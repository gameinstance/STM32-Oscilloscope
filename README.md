# STM32-Oscilloscope

STM32 Simple Digital Oscilloscope

Specifications:

- One input channel
- 2.57 Msps ADC, accepting signal frequencies up to 1.28 MHz
- Calculates minimum, maximum and average values
- Spectrum FFT analysis
- Fundamental frequency detection
- (Optional) SD card export of signal wave shape and spectrum
- Freeze function
- Sampling rate selection

## Parts

- ILI9341 TFT display
- STM32F103C8 a.k.a Blue Pill
- Rotary Encoder with push/click

## Files

STM32_Simple_F103: STM32F103C8 files
